# エフェクトを挿す

これまでの章では、`gain()` や `pan()` といった OrbitScore 内蔵の機能で音を調整してきました。OrbitScore では、それに加えて外部のプラグインエフェクト（コンプレッサーやリバーブなど）をシーケンスに挿すこともできます。この章では `seq.effect()` を中心に、エフェクトの挿し方を解説します。

## seq.effect() — シーケンスにエフェクトを挿す

`effect(path)` は、そのシーケンス**だけ**にかかるエフェクトを挿すメソッドです。DAW でいう「トラックの insert」と同じ位置づけです。

```text
var drums = init global.seq
drums.audio("kick.wav")
drums.effect("./plugins/MyEffect.clap")
```

処理の順番は次のとおりです。

1. シーケンス個別の insert（`seq.effect()`）
2. マスターミックス
3. `global.effect()`（マスターチェーン、設定していれば）

`global.effect()` については別の章で扱っている想定です。ここでは「シーケンス単位でエフェクトを挿せる」という点に注目してください。

### 宣言のタイミングと失敗の扱い

`effect()` は**宣言した時点**でプラグインを読み込みます。ファイルが見つからない場合や対応していない形式の場合は、その場でエラーになります。「音が鳴らないまま気づかない」という事故を防ぐため、警告だけで無音のまま進行することはありません。

### v1 は 1 シーケンスにつき 1 基

現在のバージョンでは、1 つのシーケンスに挿せるエフェクトは 1 基だけです。同じパスのエフェクトをもう一度宣言しても何も起きません（ライブコーディング中にファイルを再評価しても壊れないようにするためです）。一方、**異なるパスのエフェクトを 2 回目に宣言するとエラー**になります。複数のエフェクトを直列につなぐ「チェーン」は、将来のバージョンで対応予定です。

```text
var drums = init global.seq
drums.audio("kick.wav")
drums.effect("./plugins/MyEffect.clap")
drums.effect("./plugins/MyEffect.clap")   // 同じパス → 何も起きない(冪等)
// drums.effect("./plugins/Other.clap")   // 異なるパス → エラー
```

## sum / aux にもエフェクトを挿せる

`seq.effect()` と同じ考え方で、グループバス（`sum`）やリターンバス（`aux`）にもエフェクトを挿せます。

```text
sum("bus").effect("./plugins/MyEffect.clap")
```

`sum` や `aux` の詳しい使い方は次の章 [sum と aux/send](./routing.md) で扱います。ここでは「バスにもシーケンスと同じ要領でエフェクトを挿せる」という点だけ押さえてください。

## v1 の制約

- 受け付けるファイル形式は **`.clap` のみ**です。`.vst3` や `.component` は現時点では対応していません。
- パスはフルパスでも相対パスでも指定できます。
- プラグイン名だけで指定する仕組み（名前指し・補完）は現在準備中です（#463）。当面はファイルパスで指定してください。

```text
drums.effect("~/plugins/TAL-Reverb-4.clap")   // フルパス
drums.effect("./plugins/MyEffect.clap")       // 相対パス
```
