# sum と aux/send

前の章では、1 つのシーケンスにエフェクトを挿す方法を見ました。この章では、複数のシーケンスをまとめて扱う「バス」の仕組みを解説します。OrbitScore には 2 種類のバスがあります。**sum（グループバス）** と **aux（リターンバス）** です。

## sum — シーケンスをグループにまとめる

`global.sum(name)` でグループバスを宣言し、各シーケンスの `output(name)` でそのバスに送ります。

```text
global.sum("drum")

kick.output("drum")
snare.output("drum")
```

グループバスにもエフェクトを挿せます。バスにまとめてから 1 基のコンプレッサーをかける、といった使い方ができます。

```text
sum("bus").effect("GlueComp")
```

エフェクトはチェーン（配列）でも挿せます。複数プラグインの直列接続や `Gain(db: n)` のような標準プラグインの使い方は [エフェクトを挿す](./effects.md) を参照してください。

処理の順番は「シーケンス個別の insert（`seq.effect()`）→ グループバス」です。DAW の「トラック insert → グループトラック」と同じ考え方です。

### sum の制約

- `sum` は 1 段のみで、**ネスト（sum の中に sum）はできません**。
- `output(name)` で sum バスを指定するときは、事前に `global.sum(name)` で宣言しておく必要があります。宣言済みバス以外の宛先も書けます（下の「output() に書ける宛先」を参照してください）。
- `output(name)` で sum バスへ送れるのは **audio シーケンスと instrument シーケンス**です。`seq.midi()` は外部機器へ送るものなので、ミキサーの出口を持たずエラーになります。

## aux / send — 別経路に音を送る

`global.aux(name)` でリターンバスを宣言し、各シーケンスの `send(name, db)` でそのバスに音を送ります。`send` は元の音をコピーして送る仕組みなので、**元の音自体は消えず、そのまま master（または sum）へ流れ続けます**。

```text
global.aux("rev")
aux("rev").effect("TAL Reverb 4")

kick.send("rev", -12)
```

リターンバス（`aux`）には、リバーブのようなエフェクトを挿すのが典型的な使い方です。`send()` の第 2 引数は**どれだけの量を送るかを dB（デシベル）で書く値**です。`0` が原音と同じ大きさ、`-12` なら約 4 分の 1 の振幅になります。

::: danger 第 2 引数の単位が線形から dB に変わりました（2026-09-10）
以前の `send()` の第 2 引数は線形の量（0.0〜1.0 が目安）でしたが、**dB に変わりました**（core spec MX.3 / #611）。

そのため `kick.send("rev", 0.3)` は、以前の「線形 0.3（約 −10 dB）」ではなく「**+0.3 dB**（約 1.035 倍・ほぼ素通し）」として読まれます。**エラーにはならず、音だけが変わります。** 既存の譜面で `send()` を使っている場合は、第 2 引数を dB に書き直してください（線形 `0.3` に相当するのは `-10.5` です）。

名前付き引数だった `amount:` は**廃止**され、書くとエラーになります。`db:` を使ってください。
:::

送る量を一時的に止めたいときは `enabled: false` を書きます。チェーン上の位置はそのまま残るので、`true` に戻せば元の位置で鳴ります。

```text
kick.send("rev", -12, enabled: false)   // 送らない（位置は保持）
```

1 つのシーケンスから複数の `aux` に同時に送ることもできます。

```text
kick.send("rev", -12)
kick.send("delay", -6)
```

::: warning send() が使えないのは MIDI シーケンスです
`output()` と同じく、`send()` も **audio シーケンスと instrument シーケンス**で使えます。`seq.midi()` では使えません。
:::

## 書いた順番が処理の順番になります

`effect()` / `gain()` / `pan()` / `send()` / `output()` は、**書いた順に 1 本の線（オーディオライン）に並びます**。同じメソッドでも、書く位置が違えば結果が変わります。

```text
kickA.output("rev", thru: true).effect([Gain(db: -12)])   // rev へは音量を下げる前の音が行く
kickB.effect([Gain(db: -12)]).output("rev", thru: true)   // rev へは音量を下げた後の音が行く
```

`output()` の `thru:` は、そこで線が終わるかどうかを決めます。

- `thru: false`（既定）= **終端**。そこで線は終わり、後ろに書いた要素は通りません
- `thru: true` = **分岐**。その宛先へ音をコピーしつつ、線は先へ進みます

`send(name, db)` は `output(name, thru: true, db: db)` の短い書き方です。どちらで書いても結果は同じです。

`output()` も `send()` も、1 本の線の中に複数書けます。

```text
kick.output("rev", thru: true, db: -12).output("master")
```

どこにも `output()` を書かなかった場合は、線の最後に `output("master")` が書かれているものとして扱われます。これは今までどおりの動きです。

### output() に書ける宛先

| 書き方 | 意味 |
|---|---|
| `output("master")` | マスタートラック（予約語） |
| `output("名前")` | 宣言済みの `sum` バス **または `aux` バス** |
| `output("3,4")` | 物理出力の 3ch と 4ch |
| `output(変数)` | `var cue = mix.output(3, 4)` のように宣言したミキサーノード |
| `output("名前")` | 上のどれにも当たらない名前は LinkAudio チャンネル名（`global.linkAudio()` 宣言時） |

名前は**上から順に**解決されます。LinkAudio チャンネル名はいちばん最後なので、`"master"` や宣言済みのバス名を LinkAudio チャンネル名として使うことはできません。

::: warning `master` という名前のミキサーノードは宣言できません
`var master = mix.output(1, 2)` のように `master` という名前を付けるとエラーになります。`master` はマスタートラックを指す予約語だからです。別の名前（例: `var mainOut = mix.output(1, 2)`）を使ってください。

また `mix.output(1, 2)` は**物理デバイスの 1ch と 2ch**を指すのであって、マスタートラックではありません。
:::

## バスにも output() / send() / gain() / pan() が書けます

`sum` / `aux` バスも、シーケンスと同じようにオーディオラインを持ちます。`effect()` / `ui()` に加えて `output()` / `send()` / `gain()` / `pan()` が書けます。

```text
sum("drum").gain(-3).output("master")
sum("drum").send("rev", -18)
```

## v1 の正直な制約

この機能はまだ発展途上の部分があります。使う前に知っておいてほしい制約を挙げます。

::: warning PDC（レイテンシ補正）はありません
複数の経路（並列の `sum` や `aux`）にそれぞれ異なるレイテンシを持つエフェクトを挿すと、経路ごとにわずかなタイミングのズレ（位相のズレ）が生じることがあります。OrbitScore は現時点でこのズレを自動補正しません。
:::

::: tip send の post-fader 固定は解消されました（2026-09-10）
以前の `send()` は「シーケンス個別の insert（`seq.effect()`）を適用した後」の音を送る post-fader 固定でした。現在は上の「書いた順番が処理の順番になります」のとおり、**チェーンのどこに書いたかがそのままタップ位置**になります（エフェクトの前に書けばプリ、後ろに書けばポスト）。
:::

::: warning LinkAudio との併用はできません
`global.linkAudio()` を使う場合、`sum` / `aux` を含むミキサー機能（プラグインエフェクト全般）とは同時に使えません。両方を宣言すると宣言時点でエラーになります。
:::
