# エンジン設定

OrbitScore の音は **Audio Engine**（Rust 製・orbit-audio-daemon）が鳴らします。
この章では、エンジンの起動・停止と、現時点で設定できる項目 / まだできない項目を説明します。

## エンジンの起動と停止

OrbitStudio の Activity Bar にある **Audio Engine Settings** ビューから操作します。
ステータスバー右下の **OrbitScore: Stopped** をクリックしてコマンド一覧から起動することもできます。

- **Start Engine** — エンジンを起動します（ライブコーディングの前に必ず起動）
- **Start Engine (Debug)** — 詳細ログ付きで起動します（問題調査用）
- **Stop Engine** — エンジンを停止します

エンジンが起動すると、`.orbs` ファイルの評価（選択実行）で音が出せる状態になります。

## 現在の音声出力

| 項目 | 現状 |
| --- | --- |
| 出力デバイス | **Output Device** から選択（未選択のときは OS のデフォルト出力） |
| サンプリングレート | 48 kHz |
| チャンネル | ステレオ（2ch） |

::: warning まだできないこと
バッファサイズの変更・サンプリングレートの変更・マルチチャンネル出力は未実装です。
:::

## 出力デバイスを選ぶ

**Audio Engine Settings** ビューの **Output Device** を開くと、使えるデバイスが一覧されます。
選択中のデバイスには `●` が付きます。**System Default** を選ぶと OS のデフォルト出力に戻ります。
選択中のデバイスをもう一度クリックすると選択が解除され、エンジンが停止します。

エンジンが動いている間にデバイスをクリックすると、その場で切り替わります（停止と再起動は不要です）。

### 指定したデバイスから音が出なかったとき

デバイスによっては、オーディオの出力口が開いたように見えて実際には音の要求が一度も来ない、
という状態になることがあります。放置すると「エラーも出ないのに無音」になるため、エンジンは
**音の要求が本当に届くかを先に確かめてから**そのデバイスを使います。確かめられなかったときの
振る舞いは、**起動時か演奏中か**で変わります。

| いつ | どうなるか |
| --- | --- |
| エンジンの起動時 | OS のデフォルト出力に**切り替えて起動します**（無音のまま放置しません）。切り替えた理由はログに残ります |
| 演奏中の切り替え | 切り替えを**取りやめ、いま鳴っているデバイスのまま**続けます。音は止まりません |

演奏中に切り替えを取りやめた場合は、その理由が警告として表示されます。多くの場合はデバイスを
選び直せば済むので、**再起動は促されません**。次の場合だけは再起動が必要になるため、警告に
**Restart Engine** ボタンが付きます。

- 切り替えにも、元のデバイスへの復帰にも失敗した（このときだけ音が止まっています）
- 切り替え先のサンプリングレートが違う
- `ORBIT_CAPTURE_WAV` による録音中だった（録音中はデバイスを切り替えられません）
